# Use REAPER as the authoritative DAW

REAPER replaces Ardour as the authoritative mixer, timeline and automation editor. The no-purchase Ardour qualification ended in a bounded no-go, while the existing `reaper-controller` has real macOS evidence for background ReaScript, OSC, MIDI, project-file and headless-render workflows; accepting a paid REAPER licence is preferable to rebuilding that integration investment. LLM Studio will adopt the controller behind its semantic session adapter, automate safe setup where possible, and still require Gate A evidence for automation ranges, conflict handling, take replacement and reopen/export before the musical tracer.
